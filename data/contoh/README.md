# Data contoh (DUMMY)

Berkas di folder ini **dibuat acak hanya untuk menguji alur program**, bukan data
bawang putih sungguhan. Jangan dipakai untuk kesimpulan biologis apa pun.

- `genotipe_bawang_putih_dummy.vcf` — 6 sampel × 12 SNP pada kromosom chr1–chr8.
- `fenotipe_bawang_putih_dummy.csv` — sifat bobot umbi, diameter umbi, jumlah siung.

Kolom `sample_id` di CSV sengaja sama dengan nama sampel di header VCF agar bisa
dipakai menguji pencocokan Sample ID (BR-02) pada Minggu 6. Dataset Mini-VCF
benchmark resmi (25–50 sampel × 500 SNP) tetap disiapkan terpisah oleh tim.
